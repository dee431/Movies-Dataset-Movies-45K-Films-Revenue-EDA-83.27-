🎬 Blockbuster Oracle: 45K Movie Revenue Prediction & EDA
What if you could predict whether a film will bomb or hit the jackpot before shooting a single frame? This project dives deep into a rich metadata ecosystem of over 45,000 films from The Movie Database (TMDB) to decode the hidden formulas of Hollywood box office success using comprehensive Exploratory Data Analysis (EDA) and Machine Learning.
🌟 Project Highlights
Advanced Data Wrangling: Cleaned, parsed, and restructured complex, nested JSON fields (genres, production companies, cast lists) across 45,000+ raw records.
Deep-Dive Visual EDA: Uncovered hidden visual correlations between budgets, runtimes, release seasons, and massive financial returns using Seaborn and Plotly.
Predictive Modeling: Engineered high-performing regression pipelines (Random Forest, XGBoost) to forecast global movie revenue with precision.
🔍 Key EDA Discoveries
The Budget-Revenue Sweet Spot: Confirmed a strong positive correlation, though diminishing financial returns clearly kick in past a certain multi-million dollar threshold.
Genre Powerhouses: Action and Adventure genres consistently dominate gross revenues, while indie and drama films often yield higher relative return-on-investment (ROI) ratios.
Seasonal Box Office Magic: Summer blockbusters and late-year holiday releases heavily outperform shoulder-season cinematic drops.
🤖 Machine Learning Architecture
Targeted Feature Engineering: Extracted critical predictive signals, including actor popularity scores, director historical track records, and sentiment-driven keyword tags.
Model Benchmarking: Systematically compared baseline Linear Regression models against robust ensemble powerhouses like XGBoost and Random Forest Regressor.
Rigorous Evaluation: Optimized models using RMSE and R-squared metrics to minimize error margins and ensure real-world predictive reliability.
🚀 Getting Started & Usage
Quick Setup: Clone the repository, install dependencies using pip install -r requirements.txt, and explore the step-by-step Jupyter notebooks for a complete walkthrough of the data pipeline.
